# NES - доработки ЗУП КОРП для НЭС

> Проектный контекст для агента. Это ИНДЕКС: общие правила 1С/EDT/git - в `~/.claude/rules/`,
> здесь только специфика проекта. Не дублировать сюда глобальные правила.

Два EDT-проекта в одном репозитории:
- `НЭС_ЗУП` - основная конфигурация "Зарплата и управление персоналом КОРП" 3.1.38.92, режим совместимости 8.3.27.
- `НЭС_ЗУП.NES` - расширение `NES` (назначение Customization, префикс `NES`, версия 1.0.0.5).

## Железные правила (всегда)
- IF доработка меняет метаданные (новые объекты, реквизиты, табличные части, перечисления и т.п.) THEN делать ее только в основной конфигурации `НЭС_ЗУП`.
- IF доработка не меняет метаданные (код, перехватчики, формы, команды) THEN делать ее в расширении `NES`, префикс `NES` в именах.
- IF добавляется элемент на заимствованную форму `Документ.Анкета` THEN создавать его в коде в `&После("ПриСозданииНаСервере")`, а не в `Form.form`. Поймано в 7fc37460 (поле `NESСтатус`).
- IF форма заимствована в расширение THEN не удалять ее `Form.form`, `BaseForm/Form.form` и `Help/`, даже если макет не меняется: это штатная копия формы в расширении, без нее EDT не открывает форму. Поймано: b66c8b14 удалил эти файлы, форма Анкеты перестала открываться в EDT (09.10.2026).
- IF заимствуется форма THEN заимствовать и объекты, на которые она ссылается (общие картинки и т.п.), иначе EDT не загружает проект. Поймано в 0b414bb3 (`ОбщаяКартинка.КоллекцияДеревоАнкеты`).
- IF меняются свойства `Configuration.mdo` расширения THEN `configurationExtensionCompatibilityMode` = 8.3.27, как у основной конфигурации. Поймано в 8ae1f3bf (форма Анкеты не открывалась).
- IF расширение работает с реквизитом, к которому нужен доступ THEN проверить права в ролях (`ПолныеПрава`, `ДобавлениеИзменениеОтветовНаВопросыАнкет`, `ЧтениеОтветовНаВопросыАнкет`). Поймано в 0b414bb3.
- IF выдаются права в ролях THEN не включать в них `Enum.*`: перечисления доступны всем, а такой блок прав ломает загрузку расширения.

## Протокол работы
- Ветки: рабочая `dev`; задачи - в отдельных ветках, вливаются в `dev` через PR. `dev` вливается в `master` по результатам тестирования.
- Информационную базу запускает пользователь сам. Агент базу не запускает и не обновляет без просьбы.
- Автотестов пока нет, их планируется завести. <!-- TODO: выбрать YAxUnit или Vanessa -->
- Сборка `.cfe`/`.cf`/`.dt` в git не кладется (см. `.gitignore`).
- `.gitattributes` намеренно короче глобального шаблона: в репозитории `.svg` и `Template.bin` хранятся как текст, а часть `.bsl` - как двоичные. Правила `*.svg binary`, `*.bin binary`, `*.bsl text` дали сотни ложно измененных файлов у второго разработчика (09.10.2026). Новое правило EOL проверять: `git update-index --really-refresh` и `git status` должны быть пустыми.
- Новая грабля или решение -> строка в "Железные правила" с номером коммита, где поймано.

## Состав расширения NES
| Объект | Принадлежность | Зачем |
|--------|----------------|-------|
| `Документ.Анкета` (форма, модуль формы) | заимствован | вывод поля `NESСтатус` на форму кодом |
| `ОбщаяКартинка.КоллекцияДеревоАнкеты` | заимствован | нужна заимствованной форме Анкеты |

Метаданные доработки лежат в основной конфигурации: `Перечисление.NESСтатусы` и реквизит `Документ.Анкета.NESСтатус`.
Права на реквизит роли выдают по умолчанию (`setForAttributesByDefault`), права на перечисление не нужны.
